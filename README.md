# Lead Tracker

Lead Tracker is a Google Chrome extension that helps you save and manage the browser tabs you visit in one convenient place. It allows you to quickly save the current tab, manually add a tab using a URL, and delete saved tabs whenever they are no longer needed.

## Features

- **Save Current Tab:** Quickly save the URL of the currently active browser tab.
- **Add Tab Manually:** Add a tab by entering its URL manually.
- **View Saved Tabs:** Access your saved tabs directly from the extension.
- **Open Saved Tabs:** Click a saved tab to revisit the corresponding website.
- **Delete Individual Tabs:** Remove specific tabs from your saved list.
- **Delete All Tabs:** Clear all saved tabs at once when you no longer need them.

## How to Use

1. Install the Lead Tracker extension in Google Chrome.
2. Open the website you want to save.
3. Click the Lead Tracker extension icon.
4. Choose **Save Current Tab** to save the active website, or use the manual input option to add a URL.
5. Click any saved tab to revisit the website.
6. Delete individual tabs or use **Delete All Tabs** to clear the saved list.

## Use Cases

Lead Tracker is useful for keeping track of websites you visit regularly, organizing research links, saving potential leads, and quickly revisiting important pages without having to search for them again.

## Project Goal

The goal of Lead Tracker is to provide a simple and convenient way to manage important browser tabs and improve productivity while browsing.
